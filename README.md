# icsi418Y - pa3

## Description

 In this application, I built on PA2 and added features for creating projects and managing project members. I used React, Node.js, and MongoDB.

## Instuction to Run Application

### Backend

1. Open a terminal.
2. Navigate to the server folder and install the dependencies.
3. Start the backend: `node server.js`

The backend runs on port 9000.

### Frontend

1. Open another terminal.
2. Navigate to the client folder and install the dependencies.
3. Start the frontend: `npm run dev`
4. Open the local URL displayed in the terminal, usually `http://localhost:5173/`.
